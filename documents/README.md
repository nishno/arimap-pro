ახალი დოკუმენტები განათავსეთ ამ ბიბლიოთეკის შესაბამის ქვესაქაღალდეში და დაამატეთ თარიღი. განახლება აღწერეთ [UPDATE_HISTORY.md](UPDATE_HISTORY.md)-ში. ისტორიული გეგმები არ ნიშნავს, რომ ყველა აღწერილი შესაძლებლობა უკვე მზადაა; მოქმედი შეზღუდვები იხილეთ მომხმარებლის გზამკვლევსა და ცვლილებების ისტორიაში.

ფაილების ძველი და ახალი მდებარეობები შენახულია [relocation-map.json](relocation-map.json)-ში. საწყის საქაღალდეში დარჩა მხოლოდ მოკლე `README.md`, როგორც შესასვლელი ბმული; აპლიკაციის კოდი და ლიცენზია არ გადაადგილებულა.
