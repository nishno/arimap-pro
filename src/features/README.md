# Incoming Features Sandbox

This directory is used for developing new features, components, and logic in isolation before they are merged into the main codebase.

## How to use:
1. Create your new component/service here (e.g., `src/features/NewDashboard.tsx`).
2. Import and test it in a specific route or a "Dev Page".
3. Once verified, move the code to the standard `/src/components` or `/src/services` directories.
